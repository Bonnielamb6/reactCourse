# React Essentials Learning Project

This project is a hands-on React application built while learning React from scratch through a complete beginner-friendly course. It is part of my journey to become a fullstack developer and strengthen my foundation in modern frontend development.

## About this project

This app was created to practice the core principles of React step by step, starting from the basics and building confidence with practical examples.

## What I am learning

This project focuses on essential React concepts such as:

- Components
- JSX
- Props
- State
- Conditional rendering
- Basic app structure in React

## Course context

This project reflects a learning path inspired by a React course designed for beginners with no prior React experience. The course emphasizes:

- Learning React from the ground up
- Understanding why React is important
- Building practical skills through examples and exercises
- Progressing from fundamentals to more advanced topics
- Working with modern React practices

## Technologies used

- React
- Vite
- JavaScript
- CSS

## Getting started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open the local URL shown in the terminal in your browser
